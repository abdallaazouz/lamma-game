# LAMMA – لَمّة (V4)

لعبة مسابقات عائلية عربية RTL تعمل دون إنترنت على هاتف واحد (2–20 لاعبًا).

## الملفات
- index.html: الصفحة. style.css: التصميم. app.js: القوائم والجولات. games.js: الألعاب والحَكَم. data.js: الأسئلة ونص القرآن كاملًا.
- manifest.webmanifest + service-worker.js: التثبيت كتطبيق PWA والعمل دون إنترنت. assets/: الأيقونات.

## التشغيل
الـ Service Worker يحتاج http(s)، فلا يعمل بالنقر المزدوج على index.html (اللعبة نفسها تعمل، لكن بدون تثبيت). للتجربة محليًا: `python3 -m http.server 8000` ثم افتح http://localhost:8000

## النشر المجاني (اختر واحدًا)
1. Netlify Drop: ادخل app.netlify.com/drop واسحب مجلد LAMMA. يعطيك رابطًا جاهزًا.
2. Cloudflare Pages: Workers & Pages ← Create ← Pages ← Upload assets، وارفع المجلد.
3. GitHub Pages: ارفع الملفات إلى مستودع، ثم Settings ← Pages.
بعد النشر افتح الرابط على الهاتف من Chrome واختر «تثبيت» أو زر ⬇ في اللعبة.

## تحويل إلى APK
ادخل pwabuilder.com، ألصق رابط الموقع المنشور، واختر Android.

## نص القرآن
من مشروع quran-json (6236 آية). الأسئلة تُولَّد برمجيًا من النص دون تخمين، والحَكَم البشري هو المرجع النهائي. راجع المصحف عند التحكيم.

## قيود معروفة
- أسئلة العباقرة والتجويد محدودة العدد وتحتاج توسيعًا ومراجعة.
- لا يوجد اختيار بالجزء (الثلاثين)، ولا نظام نصف النهائي والنهائي، ولا شخصيات ثلاثية الأبعاد.
- الخطوط من النظام (Cairo/Tajawal إن وُجدت)، دون تحميل من الإنترنت.
