# lamma-game
LAMMA – لَمّة 🎮 لعبة مسابقات عائلية عربية تجمع 2 إلى 20 لاعبًا في تجربة مليئة بالمرح والتحدي. أسئلة عباقرة وثقافة عامة وعلوم، وتحديات القرآن الكريم، والتمثيل، وسرعة البديهة، وعجلة الحظ، وكلمة السر، والرسم والتخمين، واختبارات الذاكرة والذكاء. تنافسوا في جولات، واجمعوا النقاط، واكتشفوا الفائز. تعمل على الهاتف والكمبيوتر بواجهة عربية سهلة. لَمّة تجمع
